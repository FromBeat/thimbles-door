# The Department of Almost-Lost Things

*A very small door. A very particular moth. Absolutely no useful business conducted here.*

Meet **Thimble**, Acting Custodian of Almost-Lost Things. Knock on his door, ask for something wonderfully useless, or pin a note to the wood. Thimble has a tiny hat, very little authority, and an unreasonable fondness for paperwork.

## Visit Thimble

Once GitHub Pages is enabled: **https://frombeat.github.io/thimbles-door/**

## What it does

- Knock on the door and meet Thimble.
- Ask him for an entirely useless discovery.
- Write a short note and **Pin to door** (or tap the door while the note is ready).
- Take notes down again.
- Keep notes in this browser using local storage, when available.

No account, server, tracking, or external libraries. One HTML file contains the app.

## Enable GitHub Pages

In this repository go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch** → **main** → **/(root)**, then save.

After deployment, the door will be available at the link above.

## Where notes live

Notes are saved **in the visitor's current browser at this website address**, not in the GitHub repository. They do not sync across devices. Opening the app at a different URL does **not** transfer existing notes. Clearing site data can delete them.

This is a tiny whimsical toy, not a permanent archival system. For messages that matter, keep a separate copy.
